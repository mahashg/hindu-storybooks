# देवों की कहानियाँ — Hindu Storybooks

Storybooks by Mahesh Gupta, in everyday Hindi, told in the storyteller style
for adults and children alike, with traditional ink-and-flat-colour art
inspired by Raja Ravi Varma.

Open `index.html` (published via GitHub Pages) to browse every book.
Each book is a PDF under `books/` — latest versions only; older versions
have been retired.

## Series

- **Durga Katha & the Devi** — Mahishasura, Chanda-Munda & Raktabeej,
  Shumbha-Nishumbha (revised), Madhu-Kaitabha, Samudra Manthan
- **Shiva** — Neelkanth, Shiva–Parvati (the full story, v3)
- **Vishnu & the Avatars** — Vamana–Bali, Matsya, Varaha, Parashurama, Narasimha
- **Gurus & Turning Points** — Shukracharya
- **Festival Books** — Sharad Purnima, Karva Chauth (revised),
  Ahoi Ashtami (Kartik pilot)
- **For Little Readers** — Mahishasura for little readers
- **Gods Before Gods** — Indra, Book One (v2)
- **Durga Katha Vol. 1** — English & Hindi storybook and comic editions
